# Orbis.Nft — Number Run (Space Edition)

A high-speed cosmic math runner starring **Orbis the Astronaut**, featuring CloudFront video backgrounds, liquid-glass UI elements, neon lighting, and Anton & Condiment typography.

Open `index.html` directly in any modern browser, or serve locally:

```sh
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000`.

---

## 🚀 Features

- **Space Video Background**: Streamed looping background from CloudFront showcasing Orbis's celestial homeworld and deep space planet.
- **Orbis the Astronaut Runner**: Fully-animated custom canvas runner modeled after the Orbis character with:
  - Glossy spacesuit helmet & side communication pods
  - Life support backpack with glowing cyan LCD telemetry and multicolored status LEDs
  - Dynamic running stride, bobbing physics, and lane-switching bank angles
  - Soft ground shadow and thruster particle trails
- **Liquid Glass UI Effect**: Specular gradient borders, frosted background luminosity, and deep space backdrops.
- **Cosmic Highway**:
  - Neon green outer rails (`#6FFF00`) with intense glow
  - Cyan lane dividers with energy pulses
  - Luminous sleepers and glowing perimeter beacon lights
  - Floating liquid-glass portal gates with Anton numerals
- **Typography & Theme**:
  - **Anton** (`font-grotesk`) for headings, stats, and gate numbers
  - **Condiment** (`font-condiment`) for cursive accents
  - **System Monospace** for equations and telemetry
  - Palette: `#010828` (deep navy), `#EFF4FF` (cream text), `#6FFF00` (neon green accent)

---

## 🎮 Controls

- **Left / Right arrows** or **A / D**: steer Orbis across lanes
- **Swipe left or right**: steer on touch screens / mobile
- **Solve the centered equation** and steer into the gateway holding the correct answer!
